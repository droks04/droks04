## 📂 Projetos em destaque

### 🏷️ PromoRadar

Sistema automatizado de monitoramento de promoções em grupos do Telegram, desenvolvido para identificar ofertas de acordo com critérios personalizáveis e enviar notificações em tempo real.

**Tecnologias:** Node.js, TypeScript, PostgreSQL, Docker, GramJS e Telegram Bot API.

**Principais funcionalidades:**

- Monitoramento automatizado de mensagens.
- Filtragem de ofertas por produto e faixa de preço.
- Persistência de dados e controle de duplicidade.
- Envio de notificações via Telegram Bot.
- Conteinerização com Docker e hospedagem em nuvem.

### 🔑 Chaveiro de Milhões

Landing page comercial desenvolvida para um cliente real, com foco em presença digital, captação de leads, posicionamento em mecanismos de busca e experiência do usuário.

**Principais destaques:**

- Interface responsiva para dispositivos móveis e desktops.
- Otimização de SEO local.
- Configuração de domínio e DNS via Cloudflare.
- Integração com Google Search Console.
- Otimização de performance e experiência do usuário.
- Evolução de 67 para 92 pontos de performance mobile no PageSpeed Insights.
